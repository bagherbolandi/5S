# سامانه جامع ارزیابی 5S هلدینگ

طراحی و نمونه تعاملی فارسی برای ارزیابی 5S به تفکیک شرکت، سایت، واحد و محل.

## وضعیت فعلی

این مخزن **نمونه طراحی قابل اجرا** است، نه سامانه آماده بهره‌برداری. ورود کاربری، مجوزهای سمت سرور، پایگاه داده، ثبت ممیزی واقعی، آپلود شواهد و گردش تأیید هنوز ساخته نشده‌اند. هیچ امتیاز واقعی یا داده ساختگی عملکرد در داشبورد نمایش داده نمی‌شود.

قابلیت‌های موجود:

- اطلاعات پایه هفت شرکت و ۲۸ عنوان اعلام‌شده توسط مالک پروژه.
- انتخاب همه ۲۸ عنوان برای نور ایستا پلاستیک؛ سایر شرکت‌ها در وضعیت پیکربندی‌نشده.
- انتخاب مستقل موارد شرکت و سایت، جستجو، انتخاب همه، لغو انتخاب، پیش‌نویس و تأیید.
- جلوگیری از انتخاب سایت خارج از شرکت یا مورد خارج از فهرست تأییدشده شرکت.
- حفظ فهرست قطعی هنگام ویرایش پیش‌نویس، ثبت دلیل حذف و تشخیص تعارض نسخه.
- ذخیره محلی مرورگر، دریافت/ورود پشتیبان JSON و گزارش CSV پیکربندی.
- ۲۸ پیش‌نویس چک‌لیست، هر کدام پنج محور پیشنهادی؛ جمعاً ۱۴۰ قلم نیازمند بازنگری تخصصی.
- نمایش آزمایشی محاسبه امتیاز؛ این پاسخ‌ها ذخیره نمی‌شوند و ممیزی واقعی نیستند.

## اجرا

Node.js نسخه ۲۲ یا بالاتر؛ این نمونه وابستگی npm ندارد.

```sh
npm start
```

سپس مرورگر را روی `http://127.0.0.1:4173` باز کنید. فایل `index.html` را مستقیماً با `file://` باز نکنید؛ خواندن داده‌های JSON به سرور محلی نیاز دارد.

```sh
npm test
node build-data.mjs
```

دستور دوم پیش‌نویس چک‌لیست‌ها را از محورهای موجود در پیکربندی بازتولید می‌کند.

## نقشه مخزن

| مسیر | کاربرد |
|---|---|
| `docs/design.html` | سند طراحی تفصیلی فارسی، شامل قواعد ارزیابی و تصمیم‌های کاربر |
| `docs/architecture.md` | مدل داده، مرز شرکت و معماری هدف |
| `docs/api-contract.md` | قرارداد پیشنهادی انتخاب موارد و تأیید ممیزی |
| `docs/roadmap.md` | کارهای انجام‌شده، باقیمانده و معیار پذیرش |
| `docs/decisions.md` | تصمیم‌های مصوب گفتگو و ابهام‌های باقی‌مانده |
| `docs/worklog.md` | سابقه این مرحله و محدودیت اعتبارسنجی |
| `data/configuration.json` | اطلاعات پایه و انتخاب اولیه شرکت‌ها |
| `data/checklists.json` | بانک پیش‌نویس؛ غیرقابل انتشار تا تکمیل معیارها |
| `src/domain.js` | قواعد قابل آزمون انتخاب و محاسبه نمونه |
| `src/app.js` | رابط نمونه فارسی |

## نگهداری داده نمونه

تغییرات رابط فقط در localStorage همین مرورگر و همین آدرس ذخیره می‌شود؛ به GitHub یا سرور ارسال نمی‌شود. تنظیمات مرورگر جایگزین پایگاه داده و کنترل دسترسی نیست. از صفحه گزارش‌ها پشتیبان JSON بگیرید. نسخه اولیه ردیابی محلی دارد، ولی تاریخچه آن قابل دست‌کاری است و ردپای ممیزی عملیاتی محسوب نمی‌شود.

مخزن نباید حاوی رمز، توکن، فایل `.env`، عکس ممیزی یا داده عملیاتی باشد. فایل اکسل اصلی رمزگذاری شده و اینجا بارگذاری نشده است. خطاهای منتسب به اکسل در سند، گزارش منبع قبلی‌اند و با فایل فعلی تطبیق مستقیم نشده‌اند.

## مرحله بعد

تکمیل معیارهای سؤال با مالک هر محل، سپس پیاده‌سازی پایگاه داده و احراز هویت با کنترل دسترسی شرکت، انتشار نسخه چک‌لیست و چرخه ممیزی. انتخاب پشته سرور طبق توان تیم نگهدارنده هنوز نهایی نشده است.
