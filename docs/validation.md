# اعتبارسنجی مرحله طراحی — ۲۰۲۶/۱۱/۱۰

- ۸ آزمون Node برای اطلاعات پایه، جداسازی شرکت، پیش‌نویس/تأیید، محدودیت سایت، نسخه هم‌زمان، ورود تنظیمات، وضعیت پیش‌نویس چک‌لیست و محاسبه اجرا شد و گذشت.
- syntax فایل‌های JavaScript کنترل شد.
- سرور محلی برای صفحه اصلی و فایل‌های داده پاسخ HTTP 200 می‌دهد؛ مسیر خارج از فهرست فایل‌های مجاز پاسخ 404 می‌دهد.
- چک‌لیست‌ها شامل ۲۸ قالب و ۱۴۰ قلم پیش‌نویس‌اند؛ rubric و معیار هنوز تکمیل نشده و آماده انتشار عملیاتی نیستند.
- تلاش برای بازکردن مرورگر خودکار با timeout مواجه شد؛ بررسی بصری و اجرای انتهابه‌انتهای فرم‌ها در مرورگر تأیید نشده است. تست دامنه و پاسخ HTTP جایگزین این بررسی نیست.
- تست احراز هویت، پایگاه داده، بازیابی پشتیبان و ممیزی واقعی انجام نشده؛ این قابلیت‌ها هنوز پیاده نشده‌اند.

## بررسی دستی پیش از پذیرش نمونه

1. نور ایستا پلاستیک: ۲۸ انتخاب، ۱۲ ستادی و ۱۶ عملیاتی.
2. شرکت دیگر: انتخاب سه مورد و ذخیره پیش‌نویس؛ داشبورد همچنان پیکربندی‌نشده باشد. پس از تأیید، سه مورد نمایش داده شود.
3. سایت اشتهارد: فقط انتخاب‌های تأییدشده نورایستا خراسان قابل انتخاب؛ تغییر سایت مشهد مستقل باشد.
4. حذف مورد قطعی بدون دلیل رد شود؛ لغو همه و ذخیره پیش‌نویس فهرست قطعی را پاک نکند.
5. ورود فایل JSON نامعتبر تنظیمات فعلی را تغییر ندهد؛ round-trip فایل معتبر و گزارش CSV فارسی بررسی شود.
6. چک‌لیست با پاسخ صفر، آن را پاسخ معتبر بشمارد؛ با یک پاسخ خالی نمره نهایی ندهد.
7. صفحه در عرض موبایل، جهت راست‌به‌چپ، صفحه‌کلید و نمایش پیام خطا بررسی شود.
